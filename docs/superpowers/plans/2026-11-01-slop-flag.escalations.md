# Escalations — Slop Flag

## E1: parseJson3 join rule — spec says "joined with spaces", plan fixture requires '' within an event
- Task: 5
- Severity: P3
- Context: Plan interface comment and spec say segments joined with spaces; plan Step 1 fixture ("Hello"," world" → "Hello world") requires joining segs within an event with '' and events with ' '. ASR segs carry their own leading spaces.
- Options: A) '' within event, ' ' between events / B) ' ' everywhere (produces double spaces, normalized away, but splits word fragments)
- Default taken: A
- Fable: resolved: keep A — json3 segs carry their own spacing; '' within an event preserves words, ' ' between events avoids run-together; the plan fixture requires it.

## E3: yt-main.js run_at changed from document_idle to document_start
- Task: 5/8
- Severity: P2
- Context: requestPlayer posts once; if the isolated script's message is delivered before the MAIN listener is installed, first load falls back to null. Installing the listener early is harmless (reads player data only on request).
- Options: A) document_start for yt-main / B) keep document_idle and add retries
- Default taken: A (plan updated)
- Fable: resolved: keep A — cross-world ordering at document_idle isn't guaranteed; an early passive listener removes the race at zero cost.

## E4: Heuristic categories too easy to accumulate on human prose
- Task: 4
- Severity: P2
- Context: Reviewer probes: a news-wire paragraph hit 3 categories (0.875); a human op-ed hit 4 (0.9375), one em-dash short of flagging. Each stock phrase counted as its own category, and uniform_sentences (CV<0.35, ≥8 sentences) fires on most edited journalism.
- Options: A) collapse phrases into two categories (stock_phrases ≥2 distinct, stock_phrases_heavy ≥4 distinct) and tighten uniform_sentences to CV<0.25 with ≥15 sentences — flag then requires all 5 categories / B) keep the plan's formula
- Default taken: A (precision is the spec's product bar; heuristic is opt-in). Deviates from the spec line "Each signal is a tell category". Effective rule: a flag needs ≥4 distinct phrases plus all three structural signals.
- Fable: resolved: keep A — precision is the product bar and the heuristic is opt-in; spec prose to be updated to the effective rule.

## E5: `<html lang>` skip on YouTube reflects UI language, not video language
- Task: 7
- Severity: P2
- Context: Spec skips pages whose `<html lang>` is set and non-English. On YouTube that attribute follows the viewer's UI locale, so a German-UI user would never get any YouTube check, even for English videos.
- Options: A) don't apply the lang gate on YouTube watch pages; rely on English caption-track selection (description fallback still applies) / B) keep the spec rule
- Default taken: A
- Fable: resolved: keep A — YouTube lang follows UI locale, not video; English caption selection is the right signal (see E6).

## E6: Non-English YouTube videos reach the provider via description fallback
- Task: 5/7 (raised by Fable)
- Severity: P2
- Context: With E5, a video whose caption tracks are all non-English falls back to title+description (non-English) and is sent to Jev, against the spec's non-English non-goal.
- Options: A) when captionTracks is non-empty and none is English, return null (no classify); keep description fallback only when there are no tracks or an English track fetch fails / B) leave as is
- Default taken: A
- Fable: resolved: A (Fable's suggested default)
