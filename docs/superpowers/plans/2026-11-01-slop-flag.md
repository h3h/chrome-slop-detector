# Slop Flag Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Manifest V3 Chrome extension that classifies YouTube watch pages and article pages with a pluggable AI-text classifier (Jev by default) and flags only high-probability AI-written content.

**Architecture:** Pure logic in `src/lib/` and `src/providers/` (fully unit-tested with an injected `fetch` and a hand-rolled `chrome` stub). A module service worker routes messages, caches by text hash, rate-limits, dispatches to providers and sets the badge. An isolated-world content script gates and extracts text and renders the banner; a MAIN-world script on YouTube exposes player data over `postMessage`. Popup and Options are plain DOM. esbuild bundles to `dist/`.

**Tech Stack:** Node 22, plain ES modules (no TypeScript, no UI framework), esbuild 0.28, @mozilla/readability 0.6, vitest 5 + jsdom 30, @playwright/test 1.63.0 (pinned exactly; matches preinstalled browsers at `/opt/pw-browsers`).

**Spec:** `docs/specs/2026-11-01-slop-flag-extension.md` — read it before starting any task. Where this plan and the spec disagree, the spec wins; log an escalation.

## Global Constraints

- All extension code lives under `src/`; tests under `test/unit/` (vitest) and `test/e2e/` (Playwright); build output `dist/` (gitignored), `node_modules/` gitignored.
- ES modules everywhere (`"type": "module"` in package.json). No TypeScript. No runtime dependencies other than `@mozilla/readability`.
- Pure modules (`src/lib/*`, `src/providers/*`) must not reference `chrome` or `window` at import time; anything needing `chrome` takes it as a parameter or is in `src/background`, `src/content`, `src/popup`, `src/options`.
- Never use `innerHTML`/`outerHTML`/`insertAdjacentHTML` with dynamic data. Use `textContent` and `createElement`.
- Never log API keys or page text. `console.debug` of state transitions is fine.
- No network calls to real provider APIs in any test.
- Default threshold 0.90; ASR bump +0.05; min words 250 (articles, descriptions) / 300 (transcripts); max words 2500; rate limit 30 calls / rolling hour; provider timeout 20000 ms; cache TTL 30 days, cap 500 entries.
- Default Jev endpoint `https://api.typesafe.ai/v1/systemone`, default model `jev-1.13.0`.
- Never run the full test suite locally: no bare `rails test`, `bin/rails test`, `cucumber`, `pytest` with no path, `npm test`, or any other whole-suite run. Run only the test files named for your task. Don't hide a command from a guard by putting it in a shell variable, `sh -c "$cmd"`, a loop or a script.
- Commits: plain imperative subject; end the message with the two trailer lines
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and
  `Claude-Session: https://claude.ai/code/session_01PpgctMGFTg6U76V5MMhcWU`. Stage files by name.

**Interfaces (Produces):**

- `countWords(text: string): number` — number of `/\S+/g` matches in `normalize(text)`; `0` for empty.
- `truncateWords(text: string, max: number): {text: string, truncated: boolean}` — first `max` words of the normalized text joined by single spaces.
- `sha256Hex(text: string): Promise<string>` — lowercase hex of SHA-256 of UTF-8 bytes via `globalThis.crypto.subtle`.
- `DEFAULT_DENY: string[]` — exactly: `mail.google.com, outlook.live.com, outlook.office.com, docs.google.com, drive.google.com, notion.so, atlassian.net, slack.com, sharepoint.com, localhost, 127.0.0.1`.
- `isDenied(host: string, list: string[]): boolean` — lowercase; true if `host === entry` or `host.endsWith('.' + entry)` for any entry; also true if host matches `/^(10\.\d+\.\d+\.\d+|192\.168\.\d+\.\d+|172\.(1[6-9]|2\d|3[01])\.\d+\.\d+)$/` or ends with `.local` or `.internal`. Empty/blank list entries ignored. Note: `127.0.0.1` is only denied via the list (so tests can remove it).
- `policy.js`: `export const DEFAULT_THRESHOLD = 0.9, ASR_BUMP = 0.05, MIN_WORDS = 250, MIN_WORDS_TRANSCRIPT = 300, MAX_WORDS = 2500;` and `verdict({aiProbability, asr}, {threshold}) -> {state: 'flagged'|'clear', effectiveThreshold: number}` where `effectiveThreshold = threshold + (asr ? ASR_BUMP : 0)`, flagged iff `aiProbability >= effectiveThreshold` (compare after rounding both to 4 decimals to avoid float noise, e.g. 0.95 vs 0.9+0.05).

### Task 4: Heuristic provider and provider registry

**Model:** sonnet

**Files:**
- Create: `src/providers/heuristic.js`, `src/providers/index.js`
- Test: `test/unit/heuristic.test.js`, fixtures `test/fixtures/text-ai.txt`, `test/fixtures/text-human.txt`

**Interfaces:**
- Consumes: `normalize`, `countWords` (Task 1); `classify` from `jev.js` (Task 3).
- Produces:
  ```js
  export const PHRASES = ['delve', 'tapestry', "it's important to note", "in today's fast-paced world", 'navigate the complexities', 'a testament to', 'in conclusion', 'unlock the potential', 'ever-evolving landscape', 'embark on a journey'];
  export function scoreText(text) -> { score: number, categories: string[], tells: string[] }
  export async function classify({ text }) -> { aiProbability: score, provider: 'heuristic', model: 'heuristic-v1', raw: { categories, tells, score } }
  // index.js
  export function getProvider(name) -> { classify } | null   // 'jev' | 'heuristic'
  ```
- Scoring (deterministic). Lowercase text; also map `’` to `'` before phrase matching. Categories:
  - `phrase:<phrase>` — one category per distinct phrase present (word-boundary match; `delve` also matches `delves`, `delving`).
  - `em_dash` — count of `—` per 100 words ≥ 1.0.
  - `not_just_but` — ≥ 2 matches of `/\bnot (just|only|merely) [^.?!]{1,80}?,? but\b/`.
  - `uniform_sentences` — split on `/(?<=[.!?])\s+/`, keep sentences with ≥ 3 words; if ≥ 8 sentences and coefficient of variation of word counts < 0.35.
  - `score = 1 - Math.pow(0.5, categories.length)` → 1 cat 0.5, 2 cats 0.75, 3 cats 0.875, 4 cats 0.9375, 5 cats 0.96875.
  - Hard rule from the spec: heuristic flags only with ≥ 3 categories **and** score ≥ 0.95, so if `categories.length < 3`, cap `score` at `0.5 * (computed)`. Net effect: 5+ categories needed to reach 0.95 under the default policy. `tells` = human-readable list (e.g. `"phrase: delve"`, `"em-dash density 2.4/100 words"`).
- The SW applies `threshold = max(settings.threshold, 0.95)` when provider is heuristic (Task 6); note that here in a code comment.

  `view` shape (also what popup and content receive):

- `handleClassify` algorithm:
  1. `settings = loadSettings(chrome.storage.local)`.
  2. `minWords = source === 'transcript' ? 300 : 250`; `words = countWords(text)`; if `< minWords` → `unknown/too_short`.
  3. If provider is `jev` and no `jevApiKey` → `unknown/no_provider`.
  4. `{text: sent, truncated} = truncateWords(text, 2500)`; `textHash = sha256Hex(sent)`; `key = cacheKey({provider, model: provider==='jev'?jevModel:'heuristic-v1', textHash})`.
  5. Unless `force`, cache hit → result with `cached: true`.
  6. Else for jev: `tryConsume` false → `unknown/rate_limit`. (Heuristic does not consume the rate limit.) Call provider with `{apiKey, endpoint, model, fetch}`; on `ProviderError` → `unknown/<code>` (not cached); success → `cachePut(... {aiProbability, raw, source, asr})`.
  7. Verdict: threshold = `settings.threshold`, or `max(settings.threshold, 0.95)` for heuristic; `verdict({aiProbability, asr}, {threshold})`.
  8. Save view to `chrome.storage.session` key `tab:${tabId}` (store `aiProbability` etc.; recompute verdict on read); `setBadge`; return view.
  - Per-tab in-flight dedupe: module-level `Map<tabId, {hash, promise}>`; a second identical request for the same tab while one is in flight returns the same promise.
- `setBadge`: flagged → text `'AI'`, color `#c62828`; unknown with reason not in `['too_short','no_provider']` → `'?'`, color `#757575`; otherwise `''`. Always pass `tabId`.
- `sw.js`: imports core; `chrome.runtime.onMessage.addListener((msg, sender, sendResponse) => {...; return true})` routing: `classify` (tabId from `sender.tab.id`), `get-tab-state` (`msg.tabId`), `check-tab` (`msg.tabId`, forwards `{type:'run-check', force: !!msg.force}` to the tab via `chrome.tabs.sendMessage` and returns `{ok:true}`), `deny-host` (`msg.host`), `test-provider`, `get-settings`, `save-settings` (`msg.patch`; returns `{ok, settings}` or `{ok:false, error}`). Errors → `sendResponse({error: String(e.message)})`. `chrome.tabs.onRemoved` → remove `tab:${id}` from session. `fetch` passed as `(...a) => fetch(...a)`.
